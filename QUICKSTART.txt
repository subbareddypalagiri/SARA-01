📋 HOW IT WORKS

User Flow:
  1. User selects text on ChatGPT
  2. Extension detects selection
  3. ✨ SRA button appears (Shadow DOM)
  4. User clicks button → sees prompt menu
  5. User picks: Improve/Simplify/Fix/Expand
  6. Background.js calls Gemini 1.5 Flash API
  7. Content.js shows diff preview (original vs improved)
  8. User clicks "Apply Changes"
  9. Text updates with React event triggering
  10. ChatGPT's state updates properly

Technical Flow:
  content.js → (message) → background.js → Gemini API → background.js → content.js
  
  With:
    • Shadow DOM for CSS isolation
    • Event dispatching for React state sync
    • HTML escaping for XSS prevention
    • Proper error handling and user feedback

🔑 KEY CODE HIGHLIGHTS

BACKGROUND.JS (Service Worker):
  • Receives messages with: { action: 'regenerateText', text, prompt }
  • Retrieves API key: chrome.storage.local.get(['geminiApiKey'])
  • Calls Gemini: fetch() to gemini-1.5-flash:generateContent
  • Error handling: if (response.status === 429) { "Quota exceeded..." }
  • Returns: { success: true, result: "..." }

CONTENT.JS (UI + Text Editing):
  • Shadow DOM: container.attachShadow({ mode: 'open' })
  • Selection: window.getSelection().getRangeAt(0)
  • React sync: new Event('input', { bubbles: true })
  • XSS safe: escapeHtml() for all user-visible text
  • Insertion: selectedRange.deleteContents(); selectedRange.insertNode()

POPUP.JS (Settings):
  • Storage: chrome.storage.local.set({ geminiApiKey: key })
  • Test: fetch() to Gemini API to validate before saving
  • Status: showStatus(message, type) with auto-dismiss

❓ TROUBLESHOOTING

"Extension not appearing on ChatGPT"
  → Reload extension (chrome://extensions/ refresh button)
  → Reload ChatGPT page (F5 or Ctrl+R)
  → Check console for errors (F12 → Console tab)

"API calls failing"
  → Verify API key is valid (use Test Connection)
  → Check internet connection
  → Ensure Gemini API is enabled in Google Cloud
  → Check free tier quota (15 requests/min)

"Text not updating in ChatGPT"
  → Try text without extra whitespace
  → Refresh page and try again
  → Check browser console for JS errors
  → Verify you have the latest Chrome version

📞 API ENDPOINTS

Gemini 1.5 Flash:
  POST https://generativelanguage.googleapis.com/v1beta/models/gemini-1.5-flash:generateContent?key=YOUR_API_KEY
  
  Body:
  {
    "contents": [{
      "parts": [{ "text": "prompt + original_text" }]
    }],
    "generationConfig": {
      "temperature": 0.3,
      "maxOutputTokens": 2048
    }
  }

Response:
  {
    "candidates": [{
      "content": {
        "parts": [{
          "text": "regenerated text here"
        }]
      }
    }]
  }
