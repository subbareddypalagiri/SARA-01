MESSAGE FLOW (COMPLETE)
================================================================================

User selects text
  ↓
✨ SRA button appears
  ↓
User clicks button
  ↓
Floating menu appears with 4 options
  ↓
User selects option (or enters custom instruction)
  ↓
Message sent to background:
  {
    action: 'REGENERATE',
    text: '[selected text]',
    instruction: '[user instruction]'
  }
  ↓
Background.js receives message
  ↓
Builds Gemini API payload:
  "Instructions: [instruction]
  
   Original Text: "[text]"
   
   Provide ONLY the regenerated text..."
  ↓
Calls Gemini 2.5 Flash (v1beta)
  ↓
API returns regenerated text
  ↓
Response sent back to content.js
  ↓
lockedRange.deleteContents()
lockedRange.insertNode(newText)
dispatch('input' event)
  ↓
ChatGPT detects change and saves
  ↓
✅ Done

================================================================================
TROUBLESHOOTING
================================================================================

Issue: Menu doesn't appear
  → Check console (F12): Is "[SRA] Locked Text:" logged?
  → If not, selection wasn't locked. Try selecting again.

Issue: "Error: API Key is missing"
  → Open extension popup
  → Verify API key is entered
  → Click "Test Connection" to verify

Issue: "Error 429: Too many requests"
  → API quota exceeded
  → Wait a few minutes
  → Retry the operation

Issue: Text doesn't replace in ChatGPT
  → Check console for errors
  → Verify 'input' event is being dispatched
  → Refresh page if needed

Issue: Menu closes immediately
  → Normal behavior (50ms delay to prevent self-close)
  → Try again - should work on second attempt
