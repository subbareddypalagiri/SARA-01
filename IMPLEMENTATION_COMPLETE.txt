🔄 DATA FLOW
───────────────────────────────────────────────────────────────────────────────

SETUP:
  User opens popup
      ↓
  Model dropdown shows saved selection or defaults to gemini-1.5-flash
      ↓
  User enters API key and selects model
      ↓
  User clicks "Save Settings"
      ↓
  chrome.storage.local = {
    geminiApiKey: "AIza...",
    selectedModel: "gemini-1.5-flash" (or selected model)
  }

USAGE:
  User selects text on ChatGPT
      ↓
  Clicks ✨ SRA button
      ↓
  Background script retrieves API key and selectedModel
      ↓
  Builds fetch URL: /v1/models/${selectedModel}:generateContent
      ↓
  Makes API call
      ↓
  If success: Returns regenerated text
  If 404: Shows "Model not available for your tier"
  If other error: Shows appropriate error message

💻 CODE EXAMPLES
───────────────────────────────────────────────────────────────────────────────

POPUP.HTML - Model Dropdown:
  <select id="modelSelect">
    <optgroup label="Recommended (Free Tier)">
      <option value="gemini-1.5-flash">Gemini 1.5 Flash (Free)</option>
    </optgroup>
    <optgroup label="Premium Models">
      <option value="gemini-1.5-pro">Gemini 1.5 Pro</option>
      <option value="gemini-2.0-flash">Gemini 2.0 Flash</option>
      ...
    </optgroup>
  </select>

POPUP.JS - Load & Save:
  // Load
  const stored = await chrome.storage.local.get(['geminiApiKey', 'selectedModel']);
  if (stored.selectedModel) {
    modelSelect.value = stored.selectedModel;
  }
  
  // Save
  await chrome.storage.local.set({ 
    geminiApiKey: apiKey,
    selectedModel: selectedModel 
  });

BACKGROUND.JS - Dynamic Endpoint:
  const result = await chrome.storage.local.get(['geminiApiKey', 'selectedModel']);
  apiKey = result.geminiApiKey;
  selectedModel = result.selectedModel || 'gemini-1.5-flash';
  
  const url = `https://generativelanguage.googleapis.com/v1/models/${selectedModel}:generateContent?key=${apiKey}`;
